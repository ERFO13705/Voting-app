# Заведения общепита г. Сергиев Посад — сбор и рейтинг

## Быстрый старт для не-программиста (без ключей, через браузер)

Программа сама откроет Яндекс Карты в настоящем окне Chrome, **медленно** (пауза 6–12 секунд
на каждое действие), найдёт заведения по запросам «кафе», «ресторан», «пиццерия» и т.д., откроет
карточку каждого и запишет рейтинг, число оценок и статус (работает / закрыто / закрыто навсегда).
В конце получится таблица **`data/ranking.csv`** (открывается в Excel) и `data/ranking.md`.

### Windows
1. Установите Python: https://www.python.org/downloads/ → скачайте, запустите установщик и на
   первом экране **поставьте галочку «Add python.exe to PATH»**, затем Install.
2. Скачайте проект: на странице репозитория на GitHub нажмите зелёную кнопку **Code → Download ZIP**
   (ветка `claude/charming-keller-f1ebf7`), распакуйте архив.
3. Откройте папку `sergiev-posad-food` и **дважды щёлкните `START_WINDOWS.bat`**.
   При первом запуске он сам скачает всё нужное (несколько минут), потом откроется окно браузера.
4. Сначала пройдёт быстрая самопроверка на примере Dodo, потом полный прогон. Не закрывайте окна и не
   трогайте мышью в браузере. Если Яндекс покажет капчу («Вы не робот») — программа подаст звуковой
   сигнал и будет ждать: решите капчу в окне браузера, и она продолжит сама (Enter нажимать не нужно).
   После каждой капчи программа замедляется, чтобы капч было меньше. Сама капчу программа не решает.
5. Весь прогон занимает примерно 1–2 часа. Можно остановить (Ctrl+C или закрыть окно) и запустить
   снова — продолжит с того же места. Готовая таблица откроется сама в папке `data`.

### Mac / Linux
Установите Python 3, затем дважды щёлкните `START_MAC_LINUX.command` (или в терминале:
`./START_MAC_LINUX.command`).

### Если что-то пошло не так
- Таблица пустая или у многих нет рейтинга — Яндекс мог изменить вёрстку. Запустите в терминале
  `python -m sergiev_food check` и пришлите содержимое папки `data/debug`
  и текст из чёрного окна — по ним можно поправить разбор.
- Хотите добавить заведение вручную — положите ссылки на карточки (по одной на строку) в файл
  `urls.txt` рядом и запустите `python -m sergiev_food browse --extra-urls urls.txt`.
- «Вне города»: заведения, у которых в адресе нет «Сергиев Посад», исключаются из таблицы
  (`--keep-outside` вернёт их).

# Для программистов

Python 3.9+, без внешних зависимостей.

## Как запускать

```bash
cd sergiev-posad-food
export YANDEX_API_KEY=...        # ключ Yandex Search API (поиск по организациям)

python -m sergiev_food collect   # 1. найти заведения -> data/places.json
python -m sergiev_food enrich    # 2. рейтинг, оценки, статус со страниц организаций
python -m sergiev_food rank      # 3. data/ranking.csv и data/ranking.md
# или всё сразу: python -m sergiev_food all
```

Полезные опции: `--extra-urls urls.txt` (ссылки на карточки, которых нет в выдаче API, например
пример Dodo из задачи), `--delay 8` (пауза между страницами), `--limit 20` (пробный прогон),
`--dump-dir debug/` (сохранять HTML, который не удалось разобрать), `--m 10` (вес сомнения).

`enrich` возобновляемый: после каждой организации прогресс пишется в `places.json`; при капче
сбор останавливается, повторный запуск продолжит с места остановки.

## Как ранжируется

1. Группа статуса: работает → статус неизвестен → временно закрыто → закрыто навсегда/удалено.
2. Внутри группы — взвешенный балл `v/(v+m)·R + m/(v+m)·C` (R — рейтинг, v — число оценок,
   C — средний рейтинг по городу, m=10), чтобы 5.0 по двум оценкам не обгоняло 4.7 по 800.
3. Заведения без рейтинга — в конце своей группы.

## Режим браузера (`browse`)

`python -m sergiev_food browse` — без ключей: Playwright (Chromium, окно видимое, профиль в
`data/browser-profile`), прокрутка выдачи, сбор ссылок `/org/<slug>/<id>`, затем карточки. Капчу решает
человек. Названия/адреса берутся из `<title>`, если страницы нет в API-выдаче. Если в `state-view`
рейтинг не нашёлся, используется запасной разбор по видимому тексту (`parse_match = text`).

## Что проверено, а что нет

Браузерный режим прогнан только против локального мок-сервера (поиск → прокрутка → карточки → разбор), не против настоящего Яндекса.

Тесты (`python -m unittest discover -s tests`) покрывают разбор ответа API, фильтр по городу/категориям,
пагинацию, разбор страницы организации на синтетическом HTML, остановку по капче и ранжирование.

**Не проверялось на живых данных Яндекса** (из среды разработки доступ к Яндексу закрыт):
структура `state-view` на странице организации и тексты признака «закрыто навсегда» — это эвристики.
На первом запуске сделайте `enrich --limit 5 --dump-dir debug/` и проверьте колонку `parse_match`
в `places.json` (`exact` — ок, `loose`/`none` — разбор нужно подправить в `enrich.py`).

## Ограничения

- Условия Яндекса запрещают автоматизированный сбор страниц Карт; `enrich` ходит медленно и по одной
  странице, но используйте его на свой риск и для личного анализа. Для коммерческого использования
  данных о рейтингах нужны лицензионные условия Яндекса.
- Бесплатный ключ API ограничен по числу запросов в сутки; один полный `collect` — около 100–200 запросов.
- Организации, уже удалённые из справочника, API может не отдавать вовсе — их можно добавить через `--extra-urls`.
